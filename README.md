RFP Tuning Maps

These maps are provided for personal and off-road use only. Use them at your own risk and always verify that a map is appropriate for your vehicle, hardware, fuel, and local regulations.
Compatibility and Project Status

These are legacy maps designed for use with MHD. They are currently not compatible with MHD+. MHD+ support may be added in the future as this project is revived and maintained as a hobby.

If you would like to convert a map for MHD+, feel free to submit a pull request.
Supported Engines

Current and planned engine support includes:

    N54
    N55 E- and F-Series
    B58
    S58
    N63
    S63

B58, S58, N63, and S63 maps are supported only on unlocked ECUs and have been tested using bench-flashed ECUs.
Requesting Unlisted Maps

If you need a map for a vehicle or configuration that is not currently listed, please open an issue and attach a stock MHD .bin readout from the vehicle.

I will create and upload a base file when possible, then close the issue once the file has been added to the repository.
Map Disclaimer

All maps provided in this repository are base maps. Only N54 Stage 1-3 maps are high performance maps. They offer improved performance over the factory calibration, but they are not specifically tailored to your individual vehicle.

Unless you have contacted me regarding a custom tune, log reviews will be performed only as time permits. Always monitor the vehicle carefully after flashing a map, and discontinue use if you observe unsafe boost, ignition corrections, fuel-pressure issues, excessive temperatures, or other abnormal behavior.



These maps are intended as starting points. You may modify them at your own discretion, but you are responsible for validating the results.
Stage Guidelines

The following guidelines are general recommendations:

    Stage 1: Stock hardware or intake modifications
    Stage 1.5: Intake modifications and FMIC, where applicable
    Stage 2: Downpipes and intake modifications
    Stage 3: Full bolt-ons and upgraded inlets, where applicable
    Stage 3.5: TD03-H turbos, which are modified stock housings with modified cartridge. Ex: Vargas S1, Pure S1, Aliexpress special 15T, etc.
    Hybrid Turbo: Full bolt-ons with hybrid turbochargers; generally considered Stage 4
    Single Turbo: Full bolt-ons with a single-turbo conversion

Single-turbo setups are supported only when using a manual boost controller or a compatible electronic boost controller. MHD+ PID boost control is not currently integrated.
